# Rediseño UX

Adaptación visual inspirada en la referencia “Learning App For Kids”: paleta pastel turquesa/rosa/amarillo, tarjetas redondeadas, botones táctiles, navegación simplificada y estilo mobile-first.

Se mantiene la arquitectura SEO y las funcionalidades existentes. El rediseño se aplica a layout global, home, navegación, páginas de recursos, tablas individuales, juego, teclado, tablas estáticas y componentes compartidos.
